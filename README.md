# Cafe Lumière

自家焙煎コーヒーと手作りスイーツをテーマにした、スマホ対応のカフェ紹介サイトです。

## 構成

- `index.html` — ページ構造
- `style.css` — スタイル（レスポンシブ対応）
- `script.js` — メニュー切替・フォーム検証・スクロール演出などの動作

## 使い方

リポジトリを取得後、`index.html` をブラウザで開くか、簡易サーバーを立てて確認してください。

```bash
python3 -m http.server 8000
```

`http://localhost:8000` にアクセスします。
